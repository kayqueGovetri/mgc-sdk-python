# Object Storage

Object Storage provides scalable storage for files and other unstructured data.

Resources are organized into **buckets**, which contain the objects stored in Object Storage.

## Resources

| Resource            | Description                                            |
| ------------------- | ------------------------------------------------------ |
| [Buckets](buckets/) | Create, manage and configure Object Storage buckets.   |
| [Objects](objects/) | Upload, download and manage objects stored in buckets. |

## Available

### Buckets

Manage the lifecycle and configuration of Object Storage buckets.

* Create and delete buckets
* Check whether a bucket exists
* List buckets
* Configure bucket ACLs
* Configure CORS
* Manage bucket policies
* Configure versioning

See the [Buckets documentation](buckets/).

### Objects

Object management will be documented here as the Object Storage object operations become available.

See the [Objects documentation](objects/).
